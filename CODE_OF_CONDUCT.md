# Code of Conduct

## Our pledge

We are committed to making participation in the DeskMCP community a harassment-free experience for everyone, regardless of background, identity, experience level, or personal characteristics.

## Expected behavior

Contributors and participants should:

- Be respectful, constructive, and technically focused.
- Assume good faith while challenging ideas and implementations.
- Give actionable feedback without personal attacks or harassment.
- Respect privacy and never post API keys, credentials, private files, or other sensitive information in public issues or discussions.
- Follow responsible disclosure practices for security vulnerabilities.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, deliberate disclosure of secrets or private information, and sustained disruptive behavior are not acceptable.

## Security reports

Do not disclose exploitable security issues publicly. Use GitHub Private Vulnerability Reporting for DeskMCP security reports:
https://github.com/edmen12/deskmcp/security/advisories/new

## Enforcement

Project maintainers may edit, hide, or remove contributions that violate this Code of Conduct and may temporarily or permanently restrict participation when necessary to protect the community.

For conduct concerns that should not be public, contact the maintainer through the private channels listed in the repository support and security documentation.

## Scope

This Code of Conduct applies in DeskMCP project spaces, including issues, pull requests, discussions, release channels, and other project-managed community spaces.
