# DeskMCP Brand System

DeskMCP is a personal open-source project by **edmen12** and should remain independent from unrelated commercial brands.

## Brand

- Product name: **DeskMCP**
- Repository name: `deskmcp`
- Tagline: **Your desktop. Connected to AI.**
- Positioning: **Open-source local desktop bridge for ChatGPT.**
- Voice: technical, calm, security-first, concise.

## Logo

The mark combines an **M**, a secure **door/gateway**, and a lit **connection path**. Use the mark alone for app, tray and favicon-size contexts. Use the full name `DeskMCP` in headings and installer UI.

Primary assets live under `assets/brand/`:

- `deskmcp-mark.svg` — canonical vector mark
- `deskmcp-mark-256.png` — README/social raster mark
- `DeskMCP.ico` — Windows app/tray/installer icon

Keep DeskMCP independent from unrelated commercial brands, products, industries, or company identity systems.
## Color system

| Token | Hex | Use |

Primary gradient: `#2DE0D8 → #22B8FF → #2563EB`.

## UI rules

Use solid cards, restrained shadows, rounded geometry and the brand gradient only for identity or primary actions. Health colors must retain semantic meaning: do not recolor Ready/Live green into blue. Full Control remains red. Prefer actual product screenshots over decorative mockups in technical documentation.

At 16–32 px, use the mark without wordmark or tagline. The tray tooltip should remain plain text: `DeskMCP · <state> · <profile>`.
