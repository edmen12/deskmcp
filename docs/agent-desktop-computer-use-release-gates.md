# Agent Desktop / Computer Use — no-upgrade release gates (2026-10-08)

**Owner-confirmed requirement (2026-10-09):** Agent uses the **real local Windows virtual Desktop 2**, not a VM or hidden Win32 Desktop Object. **A brief Desktop 1 app appearance during startup is acceptable if the window is promptly moved to Desktop 2.** During **autonomous Computer Use**, Agent must NOT switch away from the owner's current desktop, steal their keyboard/mouse/focus, or fall back to global SendInput. A **deliberate and owner-aware human handoff** (account login, OTP, permission, manual action) may bring Desktop 2 into view; Agent must pause and must never forcibly return the owner to Desktop 1. Manual owner Desktop1/2 switching stays unrestricted. **No upgrade of installed 0.9.23 before completed E2E acceptance and owner approval.** See `docs/desktop2-operator-handoff-contract.md`.
